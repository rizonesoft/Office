# Rizonesoft Office wordmark and lockups

Generated by `python scripts/build-icons.py` from `scripts/lib/brand_design.py`; do not edit by hand.

The wordmark is set in Plus Jakarta Sans (SIL Open Font License 1.1, `design/fonts/plus-jakarta-sans/`): "Rizonesoft" in weight 700 and the product name in weight 400 in a quieter colour. All text is converted to outlines, so the artwork looks the same on machines without the font.

| File | Use |
| ---- | --- |
| `svg/rizonesoft-office-wordmark-{light,dark}.svg` | Text only, for places that already show the logo |
| `svg/rizonesoft-office-lockup-{light,dark}.svg` | Suite logo and wordmark: splash screen, website, README |
| `svg/rizonesoft-<app>-lockup-{light,dark}.svg` | App icon and "Rizonesoft Write" and so on: About boxes, Backstage |
| `png/<name>-<height>.png` | Each SVG at 1x and 2x height |

`light` artwork is for light backgrounds (dark ink); `dark` artwork is for dark backgrounds (light ink).

| Theme | Ink | Product name |
| ----- | --- | ------------ |
| light | `#1f2a44` | `#5b6780` |
| dark | `#f2f4f8` | `#aab4c8` |
