# Rizonesoft Office implementation plan

Generated by `python scripts/todo-graph.py plan --sync`; do not edit by hand. Edit the TODO sections (including their Phase and Needs fields) and regenerate. The boxes below are a projection of each file's Implementation Order table and flip in exactly one place: the stamp written by review.

The acceptance bar is Every element in design/inventory works in its app at its inventoried position (for Outlook, Visio and Project, its modernised position in design/SPEC.md) or is excluded with a recorded reason, OOXML files round-trip, every app beats Office's measured time on each D03 T01 §29 workload, and each app ships as a draft release.

Format and rules: `todo/README.md`. Run sections with the `process-plan`, `process-phase` and `process-todo-section` skills; `python scripts/todo-graph.py query ready` lists what can run now. Pasting a whole row from a table below into `process todo section:` is a complete instruction.
