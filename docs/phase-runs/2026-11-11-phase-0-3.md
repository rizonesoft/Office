## Lessons

- A fake child that reads its standard input in the locale encoding passes in a shell that sets `PYTHONIOENCODING` and fails in one that does not: decode a harness's input explicitly, and ask a Python child whose output is decoded as UTF-8 for UTF-8 (`PYTHONUTF8=1`).
- Run the boundary's dependency merge before the next section's `Started:` commit: `merge_prs.py` refuses while a section is in progress, so a section started during the CI wait skips that boundary's merge.
- A test that counts what Windows puts in a job beside the processes the test started passes on a desktop and fails on the hosted runner: assert on what the test itself started.
- Proving a test fails on the old code runs the old code's bugs too: the interrupt test run on the pre-fix helper left a suspended child alive for 12 minutes until it was found and ended. After a fail-before run of a process test, look for what it left.
- A Windows job's member list and count both drop a terminating member before it is signalled, so no amount of polling sees every member; the job's completion port announces each one as it joins.
- A Windows job object's member count can read 0 before the last member's process object is signalled; wait on each member's handle for proof that a tree is gone (`scripts/lib/process_tree.py`).
