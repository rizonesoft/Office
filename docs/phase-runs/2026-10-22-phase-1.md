## Lessons

- A heredoc turned a regex's `` into a backspace, which made a test vacuous; it was caught only because the mutation run showed no failures. Tests that parse markup now assert a minimum match count, and every touched file is scanned for control characters.

- sed-based mutation checks in Python must run with `-B`: a same-size mutation restored within a second left stale bytecode, and the clean run reported the mutation's failure. In-memory monkeypatch mutations avoid it.

- A rendered property test that samples by expected colour can be dodged by any change to how a part is painted; three rounds of patching it ended only when the input was closed instead (a glyph vocabulary of plain, fully painted, bounded shapes at documented weights), which makes the colour sampling valid by construction.
