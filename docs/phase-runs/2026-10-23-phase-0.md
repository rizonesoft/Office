## Lessons

- An edit script that asserts its anchors must also stop the commit that follows it: chain the commit on the script's success, or check the diff before committing. One no-op fix commit (b042105) went in this way.
- A reviewer finding one unpinned phrase per round signals a class: pin the whole paragraph (a hash of the line) and the rounds stop.

- A reviewer at maximum effort with no severity floor keeps widening the threat model one case per round; the loop converges only when severity is tied to real operation. The owner's fix (medium effort plus the real-operation rule) ended §12's loop in one round.
- PowerShell double-quoted strings turn backtick-letter pairs into control characters; write Markdown with backticks through Python or single-quoted here-strings.
