## Lessons

- A reviewer widening the input model one case per round (a BOM, then UTF-16) is answered by closing the whole class in one fix (every Unicode mark), not only the reported case.
- A gate is only proven when it has been seen failing: the three ci-proof branches each failed at their own step, after a first round where all three died at the install step and proved nothing.
- The new pre-commit hook refused a commit that left the findings file untracked, exactly the gap review round 1 of the review port had found.

- Three review rounds on one checker came from widening the threat model each round (well framed, then decodable, then fully valid). A first pass that writes the format's own validity rules out in full would have saved two rounds.
