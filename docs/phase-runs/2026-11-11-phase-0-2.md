## Lessons

- A run file written by the Write tool is LF, but a later checkout can make it CRLF: a scripted `.Replace("`n...")` then silently matches nothing. Edit run files with the Edit tool, or match line endings.
- A review loop on tooling scope can run indefinitely on hypotheticals: rounds 5 to 17 of D00 T03 §34 chased link and junction shapes the repository has none of. Check each finding against what the section promises and what the repository holds before funding it (now in AGENTS.md, Subagents).
- When one reader of a field gains a new meaning (a withdrawn section is not done but is settled), search every reader of that field: review round 2 of §50 found one, and the search found a second (`merge_prs.py`).
