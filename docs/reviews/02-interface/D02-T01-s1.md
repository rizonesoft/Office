## consistency: needs-attention

2. **The `integer` implementation disagrees with JSON Schema 2020-12.** `scripts/check-inventory.py:43` accepts only Python `int`. JSON Schema considers numbers with no fractional part integers, including JSON `1.0` and `1e0`. Reproduce by changing TAB’s `order` to `1.0`: the schema permits it, but this checker rejects it. Correcting this also requires checking numeric `minimum` for integral floats at lines 64-65.

## integration: advisory

A shortcut with `shortcut: "Ctrl+B"` and `target: "word.nonexistent"` passes. Later shortcut coverage therefore cannot rely on this checker to establish that an invocation target exists. Target integrity is not explicitly required by this section, so this is advisory.

## source-defect: needs-attention

The former is no behaviour sentence; the latter is no web URL. Likewise, bare `uia:`, `baseline:` and `listcommands:` pass without the build or commit described by the schema. Reproduce by applying those values to BOLD in the existing behaviour-gate test. Validate meaningful text and usable source identifiers at their defining layer.
