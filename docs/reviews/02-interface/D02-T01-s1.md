## adversarial: needs-attention

1. **Uncaught decoder failures bypass the documented error handling.** `scripts/check-inventory.py:93-95` catches neither `RecursionError` nor plain `ValueError`. A file containing 10,000 nested arrays triggers `RecursionError`; on Python versions with the integer conversion limit enabled, a sufficiently long integer triggers `ValueError`. Both escape `main()` and print tracebacks instead of returning the documented parse-error exit code 2. Add refusal tests for both error paths.

## consistency: needs-attention

2. **The `integer` implementation disagrees with JSON Schema 2020-12.** `scripts/check-inventory.py:43` accepts only Python `int`. JSON Schema considers numbers with no fractional part integers, including JSON `1.0` and `1e0`. Reproduce by changing TAB’s `order` to `1.0`: the schema permits it, but this checker rejects it. Correcting this also requires checking numeric `minimum` for integral floats at lines 64-65.

## integration: advisory

3. **Shortcut targets can silently reference nonexistent records.** `design/inventory/schema.json:35` describes `target` as a command or control ID, but `scripts/check-inventory.py:143-145` checks only `parent`. A shortcut with `shortcut: "Ctrl+B"` and `target: "word.nonexistent"` passes. Later shortcut coverage therefore cannot rely on this checker to establish that an invocation target exists. Target integrity is not explicitly required by this section, so this is advisory.

## source-defect: needs-attention
