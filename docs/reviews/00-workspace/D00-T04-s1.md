1. **P1, lines 63, 69–70:** The lock schema allows one archive and one version per tool and architecture, but vcpkg requires both a registry archive and a separately versioned executable. No step defines how these become one usable installation. Add component pins, destination layout, assembly and completion rules, and separate registry/tool version checks. Test that both components are installed together and failure of either cannot mark vcpkg installed.

2. **P1, lines 66–67, 75:** Installation validity depends on a receipt and existing directories, not the installed programs or required resources. Deleting an executable or LLVM resource file leaves `--check` green, and bootstrap skips repair. Define the required installed payload, verify it before accepting or skipping an installation, and test missing or damaged payload detection and repair. Version output alone does not prove that retained runtime resources work.

3. **P2, lines 65–67:** Recovery omits an existing current-version destination with a missing, malformed or stale receipt. An interruption after the directory rename but before receipt publication creates this state; the next rename cannot replace a populated directory on Windows. Define replacement/recovery for that destination, preferably publish the receipt inside staging before promotion, and test interruption after rename plus a changed lock entry at the same version.

4. **P2, line 64:** The download is bounded by bytes but not time. A stalled connection can indefinitely block bootstrap and the launcher that later invokes it. Specify connection/read timeouts and an overall deadline, actionable nonzero failure, temporary-file cleanup and successful retry. Add fixture tests for stalled and interrupted downloads.

5. **P2, lines 64–65, 75:** The prescribed tests do not prove several explicit refusal requirements: exceeding `size`, absolute archive paths, and links escaping the extraction directory. A downloader without a size limit or an extractor rejecting only `../escape.txt` can pass every named checkpoint. Add negative fixtures for those behaviours and exercise both ZIP and TAR.XZ extraction, plus standalone EXE installation.
