# Review findings: D00 T03 §7 Run Guard Robustness Fixes

Reported by the owner on 2026-10-21 (found by independent review in a sibling repository); each verified in Office's `scripts/campaign_guard.py` before fixing. Tests: `scripts/tests/test_campaign_guard.py` class `Robustness`.

## The three defects

1. A symlink or device in the working tree could break or stall the Stop hook. `fingerprint` called `os.stat` (following links) on every untracked path and `open()` on the first 500. Fixed in `_untracked_entry`: `os.lstat`; a symlink counts by its target text, a FIFO, device or socket by its type, and only a regular file is opened (non-blocking, rechecked with `fstat`); a path past both bounds makes no filesystem call. Before the fix: `PermissionError: [Errno 13] Permission denied: '...\ws\dirlink'` (the hook raised on a symlink to a directory) and `AssertionError: 0 != 2 : the third untracked path was touched`. After: both tests pass.
2. A re-point without `--phase` reset the run to phase 0 (`int(opts.get("phase", "0"))`). Fixed: `--phase` is optional; a re-point of this session's own run keeps the guard's phase, and a new run without one is refused. Before: `AssertionError: GuardError not raised`. After: passes, through the function and the CLI.
3. An interrupted `end` could resume a stopped run: the pending cancellation was written, then the guard deleted, so a session dying between them left a guard `whoami` reported as `OWNER`. Fixed: `end` first marks the guard `ended` atomically; `read_guard` treats an ended guard as gone, and `whoami`, `acquire` and `end` finish its deletion. Before: `AssertionError: 'OWNER run=f74f1ab8773f scope=plan' != 'NO GUARD'`. After: `whoami` prints `NO GUARD`, the Stop hook lets the turn end, and a later `acquire` creates a fresh run.

Gates: `python -m unittest discover -s scripts/tests -p "test_campaign_guard.py"` -> Ran 33 tests, OK. The live run read through the changed code: `whoami` -> `OWNER run=d5cf086c0c58 scope=plan`, `health` ok, and the Stop hook still blocks this session's turn.
